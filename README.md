# Автоматизированная система управления библиотекой (Library Management System)

Информационная система для автоматизации работы библиотечного фонда, учёта читателей, контроля выдачи и возврата литературы, а также расчёта штрафов и анализа популярности изданий. Проект разработан в рамках университетской курсовой работы.

---

## Технологический стек
* **Язык программирования:** Python 3.11
* **Веб-интерфейс:** Streamlit
* **База данных:** SQLite (10 взаимосвязанных сущностей)
* **Тестирование:** `unittest` (модульное тестирование бизнес-логики)

---

## Архитектура и паттерны проектирования
В приложении реализовано **6 шаблонов проектирования**, разделенных по категориям, что обеспечивает высокую гибкость и поддерживаемость кода:
1. **Factory (Фабрика)** — инкапсуляция логики создания объектов.
2. **Builder (Строитель)** — пошаговое формирование сложных составных объектов.
3. **Facade (Фасад)** — единый упрощенный интерфейс для работы с подсистемой транзакций.
4. **Decorator (Декоратор)** — динамическое расширение функциональности объектов.
5. **Strategy (Стратегия)** — гибкий алгоритм расчёта штрафов (с учётом статуса читателя, например, льгот для студентов).
6. **Observer (Наблюдатель)** — механизм подписок и оповещений (например, уведомления о доступности забронированных книг).

---

## Структура интерфейса (Вкладки приложения)
Пользовательский интерфейс на базе **Streamlit** разделен на 6 функциональных модулей:
* **Каталог:** просмотр книг с возможностью гибкой фильтрации и поиска.
* **Выдача / Возврат:** оформление книговыдачи, контроль сроков и статусов.
* **Штрафы:** расчет и отслеживание задолженностей.
* **Бронирование:** резервирование литературы читателями.
* **Популярность:** аналитические отчеты по востребованности фонда.
* **Управление читателями:** модуль реализует полный жизненный цикл управления данными (CRUD), обеспечивая возможность создания, чтения, модификации и удаления учетных записей читателей
